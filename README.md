# 🏋️‍♂️ Brogram – Workout Planner

**Brogram** is a React.js web application that helps users plan, track, and manage their workouts.  
It provides a smooth and responsive interface built with **FantaCSS**, allowing users to easily follow their training routines and monitor progress.

---

## 🚀 Features
- ✅ Full CRUD functionality (Create, Read, Update, Delete)
- ⚛️ Built with React.js and Hooks for state management
- 🎨 Smooth and modern UI powered by FantaCSS
- 💾 Persistent workout tracking
- 🌐 Hosted and deployed online via Netlify

---

## 🧩 Tech Stack

| Category | Technology |
|-----------|-------------|
| Frontend | React.js, Vite |
| Styling | FantaCSS |
| Deployment | Netlify |

## ⚙️ Getting Started

### 1️⃣ Clone the repository
```bash
git clone https://github.com/midnightbam/portfolio.git
cd portfolio/full-stack-course/2_brogram
```

### 2️⃣ Install dependencies
```bash
npm install
```

### 3️⃣ Run locally
```bash
npm run dev
```

### 4️⃣ Build for production
```bash
npm run build
```
